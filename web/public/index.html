Twitch VOD → m3u8

Collez le lien d'une VOD Twitch (même réservée aux abonnés) pour l'ouvrir dans VLC, mpv ou tout lecteur HLS.

Aide
  • Tous les liens pointent directement vers le flux Twitch (CloudFront) : ce serveur n'est plus utilisé pendant la lecture.
  • Ouvrir dans VLC : fonctionne directement sur Android / iOS. Sur Windows, lancez une fois web\tools\windows\install-vlc-protocol.cmd pour que les liens vlc:// ouvrent VLC.
  • Copier le lien : à coller dans VLC via Média → Ouvrir un flux réseau (Ctrl+N).
  • Fichier .m3u8 : télécharge la playlist (qui ne contient que des liens Twitch) à ouvrir avec VLC.
  • HEVC : la qualité source de certaines VOD est en H.265, lisible par VLC/mpv mais pas par tous les appareils. Choisissez 1080p60/720p60 en cas de souci.
